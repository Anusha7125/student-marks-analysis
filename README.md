# Student Marks Analysis

## Description
This project analyzes student marks using Python and calculates the total, average, highest, and lowest marks.

## Objective
To practice Python data processing and basic statistical calculations.

## Tools Used
- Python
- Jupyter Notebook

## Approach
1. Store student marks in a Python list.
2. Use `sum()` to calculate the total marks.
3. Use `len()` to find the number of students.
4. Calculate the average using total marks divided by the number of students.
5. Use `max()` to find the highest mark.
6. Use `min()` to find the lowest mark.

## Results
- Total Marks: 825
- Average Marks: 82.5
- Highest Mark: 95
- Lowest Mark: 67

## Conclusion
The project demonstrates basic Python list processing and statistical calculations using student marks.
