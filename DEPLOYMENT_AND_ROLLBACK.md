# Deployment and Rollback Evidence

## Deployment
This project is a Jupyter Notebook-based Python analysis task.
It does not require a production web deployment or server configuration.

The complete solution is provided in:
`Student_Marks_Analysis.ipynb`

## Version Control
The project is maintained using GitHub for version control.

## Rollback
GitHub commit history can be used to restore a previous working version of the project.

If a future change introduces an issue, the previous working commit can be restored/reverted using Git.

Example Git commands:

```bash
git log --oneline
git revert <commit-id>
